Settings

Gemini API key

  1. Open Google AI Studio → API keys and click Create API key.
  2. Enable billing. Image models (Nano Banana) aren’t in the Free Tier – click Set up billing on your project and link a card. Then you only pay for what you generate (Nano Banana 2.1 ≈ per 1K image).
  3. Paste the key here. It’s stored only on this computer in , not in OneDrive.

Tip: in Google Cloud Billing, set up Budgets & alerts so you’re notified when spending goes over your limit.

Open-source models (Pollinations)

Z-Image Turbo, FLUX.2 klein, FLUX.1 schnell and the free AI coder in Effects run through Pollinations with one free API key – they use Pollinations’ free daily credit (“pollen”), not your Google billing. When the pollen runs out, the image models switch to Cloudflare (if connected) or to Hugging Face’s free GPUs by themselves.

  1. Get a free key ↗ – sign in at enter.pollinations.ai (free, e.g. with GitHub or Google).
  2. Create a secret key (it starts with sk_) and copy it.
  3. Click Paste & connect above. The app checks the key with Pollinations and stores it only on this computer.

Cloudflare – free backup for open-source models

When Pollinations is down or out of pollen, the open-source models and the free AI coder run on Cloudflare Workers AI instead – on its free daily allowance (about 95 FLUX.2 klein or 170 FLUX.1 schnell images a day). Z-Image Turbo is drawn by FLUX.2 klein there.

  1. Create a free account ↗ – or sign in. No card needed.
  2. Open Workers AI ↗ and click Use REST API. Copy the Account ID shown there.
  3. On the same page click Create a Workers AI API Token, confirm it and copy the token – Cloudflare shows it only once.
  4. Paste both above and click Save & check. The app checks them with Cloudflare and stores them only on this computer.

Hugging Face – free open models

The video models Wan 2.2, LTX-2.3 and LTX-Video, the image model Qwen-Image, and the other open image models whenever Pollinations can’t serve them run free on Hugging Face’s shared GPUs. There’s a daily allowance of GPU time: 2 minutes without an account, 5 minutes with a free account’s token – a few short clips or a few dozen images a day. Everything works without a token too.

  1. Create a free account ↗ – or sign in. No card needed.
  2. Create a token ↗ of the type Read and copy it (it starts with hf_).
  3. Paste it above and click Save & check. The app checks it with Hugging Face and stores it only on this computer.

Free open-source models

The app searches Hugging Face, Pollinations, Cloudflare and ComfyUI’s official templates once a day for open models that run for free – open source, and models with their author’s own license (free for personal use; each one says what its license allows) – checks it can drive them, and sorts them best first. Image models join the model menu (and Best free (auto), which tries them one after another), video models join the Video view, code models join the AI coders in Effects and Vectors. Each model’s app is checked without generating anything; the first real picture shows whether it works, and a model that fails twice is hidden for a few days.
